# studia-ebash-montaj

**Русский** · [English](README.md)

Монтаж рилсов и шортсов (9:16) из «говорящей головы» на русском — одной командой или словами в Claude Code.

Кидаешь сырое видео → получаешь готовый ролик 1080×1920:

- **вырезаны паузы** длиннее 0.4 с и **неудачные дубли** (если фраза начата несколько раз — остаётся последняя попытка);
- **вырезаны «ээ», «мм»**;
- **пословные субтитры** по центру, по 2–3 слова, текущее слово подсвечено и «подпрыгивает»;
- **кадр 9:16 следует за лицом покадрово**: камера плавно едет за тобой, когда ходишь, стоит, когда просто покачиваешься (мёртвая зона), прыгает только на склейках, где это не видно;
- **зум**: мягкий наезд 100% ↔ 108% на склейках, в длинных кусках кадр медленно приближается на 3%, чтобы статичный план «дышал»; в конце затемнение;
- **громкость −14 LUFS** (как требуют Reels/Shorts/TikTok);
- рядом лежат `.srt` и `.edl` — открыть монтаж в DaVinci Resolve / Premiere и доправить руками.

Перед рендером печатается план: что будет вырезано и почему. Его можно посмотреть и без рендера (`--dry-run`).

## Что нужно

| | |
|---|---|
| Windows 10/11 | проверено на Windows 11; на Linux/macOS должно работать, но не проверялось |
| Видеокарта NVIDIA (RTX 30/40/50) | с ней ролик в пару минут обрабатывается за ~1 мин. **Без неё тоже работает**, но в разы медленнее (процессор) |
| ~10 ГБ на диске | модели скачаются сами при первом запуске: Whisper large-v3 ~3 ГБ, PyTorch ~3 ГБ |
| [Claude Code](https://claude.com/claude-code) | по желанию — чтобы монтировать словами. Скрипты работают и без него |

## Установка (один раз, ~15 минут)

Открой PowerShell и выполни по очереди.

**1. Программы** (если ещё не стоят):

```powershell
winget install Git.Git Python.Python.3.14 Gyan.FFmpeg
```

Закрой и снова открой PowerShell — иначе `ffmpeg` не найдётся. Проверка: `ffmpeg -version`.

**2. Проект:**

```powershell
git clone https://github.com/Blum83/studia-ebash-montaj
cd studia-ebash-montaj
python -m venv .venv
.venv\Scripts\python -m pip install --upgrade pip
```

**3. PyTorch для видеокарты** (нужен для отделения голоса от музыки):

```powershell
.venv\Scripts\python -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128
```

Без NVIDIA — то же без `--index-url ...` (поставится версия для процессора).

**4. Остальное:**

```powershell
.venv\Scripts\python -m pip install -r requirements.txt
```

**5. Проверка** (без видео и видеокарты, пару секунд):

```powershell
.venv\Scripts\python test_montage.py
```

Должно напечатать `ok` и `ok makeup`.

## Как пользоваться

### Словами в Claude Code (удобнее)

Открой папку проекта в Claude Code и напиши, например:

> смонтируй `C:\Users\me\Videos\raw.mp4`

Claude сам прочитает [`CLAUDE.md`](CLAUDE.md) (там весь пайплайн и правила стиля), покажет план и отрендерит. Дальше правишь словами: «субтитры крупнее», «не режь паузы так сильно», «добавь музыку». **Каждая правка записывается в `CLAUDE.md` правилом** (раздел «My editing rules») и применяется ко всем следующим роликам — так проект учится твоему стилю.

> В `CLAUDE.md` уже есть правила автора репозитория (плавные переходы, зум на склейках и т.д.). Оставь их или удали — это твой стиль, не обязательный.

### Командой (без Claude)

```powershell
.venv\Scripts\python montage.py C:\path\raw.mp4 --dry-run   # только план: что вырежется
.venv\Scripts\python montage.py C:\path\raw.mp4             # монтаж
```

Результат — в папке `out\`: `raw_edit.mp4`, `raw.ass` (субтитры), `raw.srt`, `raw.edl`.

| Флаг | Когда |
|---|---|
| `--music` | в видео играет фоновая музыка: голос отделится от неё нейросетью, режется только голос, а трек идёт под ним целиком |
| `--denoise` | шумная комната, вентилятор, улица |
| `--makeup` | лёгкий макияж на лице (помада, румяна, сглаживание кожи) |
| `--lang=en` | речь не на русском (любой язык Whisper: `en`, `uk`, `de`…). Без флага на чужом языке скрипт остановится — иначе Whisper молча «переводит». «Ээ/мм» вырезаются только в русском |
| `--dry-run` | показать план и не рендерить |

Настройки (паузы, размер и цвет субтитров, зум…) — константы в начале [`montage.py`](montage.py), у каждой комментарий.

## Демо-ролики с озвучкой

[`demo.py`](demo.py) собирает демо фич 16:9 из слайдов, скриншотов и записей экрана: плавный наезд на нужную область, мягкие переходы, озвучка на русском, украинском или английском (голос по описанию или **твой клонированный голос**) и пословные субтитры. Всё берётся из файла сценария, пример — [`examples/robot_demo.json`](examples/robot_demo.json):

```json
{"segments": [
  {"shots": [{"src": "slides/01.png"},
             {"src": "shots/spending.png", "roi": [1170, 40, 1495, 320]},
             {"src": "live/clip.mp4", "ss": 9, "crop_top": 57, "roi": [1830, 600, 2530, 994]}],
   "text": {"ru": "Траты фана теперь разбиты по типам.", "uk": "Витрати фана тепер розбиті за типами."}}
]}
```

Пути — относительно сценария. `roi` — область для наезда (x0, y0, x1, y1 в пикселях картинки; без `roi` — медленный наезд на всю картинку). Кадры сегмента делят между собой время его текста. Материалы недели (сценарий, слайды, скриншоты) держи в `out\demo\<название>\` — они не попадают в git.

**Установка модели голоса (один раз, ~10 минут, несколько ГБ).** [OmniVoice](https://github.com/k2-fsa/OmniVoice) работает локально и бесплатно, читает ru/uk/en вместе с английскими названиями фич, клонирует голос по 10–15 с записи. На Python 3.14 не ставится, поэтому у неё своё окружение на 3.13:

```powershell
winget install Python.Python.3.13
py -3.13 -m venv .venv-tts
.venv-tts\Scripts\python -m pip install --upgrade pip
.venv-tts\Scripts\python -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128
.venv-tts\Scripts\python -m pip install omnivoice
```

Без NVIDIA — torch без `--index-url ...`; работает на процессоре, сильно медленнее. Модель скачается сама при первом запуске.

**Запуск:**

```powershell
.venv\Scripts\python make_robot.py любой_голос.wav samples\robot.mp4   # только для примера: ролик с роботом
.venv\Scripts\python demo.py examples\robot_demo.json                 # -> examples\demo_ru.mp4
.venv\Scripts\python demo.py out\demo\week\script.json --lang uk      # -> out\demo\week\demo_uk.mp4
```

| Флаг | Что делает |
|---|---|
| `--lang ru\|uk\|en` | язык озвучки (в сценарии должен быть этот текст) |
| `--design "male"` | голос создаётся по описанию один раз (`"female, low pitch"`, …) и сохраняется в `out\voices\<описание>-<язык>`, чтобы каждую неделю звучал одинаково |
| `--voice ПАПКА` | вместо этого клонировать голос из папки (см. ниже) |
| `--speed 1.2` | говорить быстрее; клон часто говорит медленнее оригинала |
| `--tts eleven` | ElevenLabs вместо OmniVoice: ключ в `secrets\elevenlabs.key`, id голоса в переменной `ELEVEN_VOICE`; `"say"` в сценарии чинит слова, которые он коверкает (`"Ctrl+W": "контрол дабл-ю"`) |

**Свой голос.** Запиши 20–40 с своими словами, тем тоном, что нужен в ролике, диктофоном телефона (голосовые Telegram сильно сжаты), в тихой комнате. Потом:

```powershell
.venv\Scripts\python make_ref.py мой_голос.m4a ru secrets\voice\me-ru     # 4-й аргумент — с какой секунды, по желанию
.venv\Scripts\python demo.py out\demo\week\script.json --voice secrets\voice\me-ru --speed 1.2
```

`make_ref.py` вырезает 7–14 с по тихим местам между словами (если образец начинается с хвоста слова, клон начинает этим звуком каждую фразу) и пишет `ref.wav` + `ref.txt`. Проверь `ref.txt`: ошибка распознавания там ухудшает клон. Клонируй только голос того, кто согласен; образцы держи в `secrets\` — они не попадают в git.

Озвучка кэшируется в папке `cache\` рядом со сценарием: пересборка с тем же текстом и голосом — секунды, переозвучиваются только изменённые фразы.

## Скиллы для Claude Code

В `.claude/skills` лежат готовые скиллы, Claude подхватит их сам:

- **Remotion** — анимированные титры, переходы, графика кодом (когда ffmpeg мало);
- **short-form-video, caption-animation, lower-thirds** — хуки, удержание, 9:16 safe areas, плашки с именами;
- **video-editing-skill** — простые bash-утилиты на ffmpeg (обрезка, ускорение, надписи).

## Если что-то не так

- **Вырезало лишнее / оставило паузы** — сначала `--dry-run`, посмотри строки `retakes:` и `fillers:`. Естественный повтор фразы («то есть… то есть») иногда принимается за дубль. Порог тишины — `SILENCE_BELOW` в `montage.py`.
- **Поменял настройки, а результат тот же** — транскрипт кешируется в `out\cache\*.words.json`, удали его.
- **`speech is 'en' ... not 'ru'`** — речь не русская, добавь `--lang=en`.
- **`ffmpeg` не найден** — перезапусти PowerShell после установки.
- **Очень долго** — нет видеокарты NVIDIA или не встал PyTorch с CUDA (шаг 3). Проверка: `.venv\Scripts\python -c "import torch; print(torch.cuda.is_available())"` → `True`.
